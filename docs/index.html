Frequently Asked Questions

⚡ How fast is cold-start execution with ttfx-rs?
Compiled natively in Rust with zero heavy runtime overhead, ttfx-rs cold-starts in ~2ms, making it ideal for high-speed terminal pipes, shell scripts, and CLI banners.
🦀 How does ttfx-rs integrate with Ratatui & TUIs?
Unlike competing CLI tools that hijack stdout, ttfx-rs provides Grid::render_to_string() to query ANSI animation frames as a string buffer and embed them inside Ratatui widgets!
🤖 How do LLMs & AI Assistants trigger text animations?
Every effect card includes a one-click LLM button that copies pre-structured system prompts with custom GradientBuilder hex colors to instruct Claude, Gemini, ChatGPT, or AGY agents.
📦 Can I import ttfx-rs as a library in my Rust crate?
Yes! ttfx-rs is published on Crates.io as a dual CLI binary and library crate. You can import Grid and ALL_EFFECTS directly into your Rust code via src/lib.rs.
🖥️ Does ttfx-rs support DEC 2026 synchronized rendering?
Yes! ttfx-rs emits DEC 2026 TTY escape sequences (\x1b[?2026h / \x1b[?2026l) to guarantee 100% flicker-free synchronized frame updates across Kitty, Alacritty, WezTerm, Ghostty, and Windows Terminal.
🎨 How do I customize text presets and gradient themes?
Cycle through text presets with the ‹ 🔀 › controls or open the 🎨 Color Studio & Map modal to adjust 4-stop gradient palettes in real-time at 120 FPS.

🏆 Strategic Architectural Wins & TUI Integration

🦀 Ratatui & TUI Widget Ergonomics
CLI tools traditionally hijack stdout, preventing embedded TUI usage. ttfx-rs solves this with grid.render_to_string(), letting developers capture ANSI animation frames into custom Ratatui Paragraph or Canvas widgets seamlessly!
✨ DEC 2026 Synchronized Frame Buffer
Prevents tearing and screen jitter by wrapping output frames in DEC 2026 escape codes (\x1b[?2026h ... \x1b[?2026l), supported by modern GPU terminal emulators (Kitty, Alacritty, WezTerm, Ghostty).
